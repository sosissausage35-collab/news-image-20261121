## The picture

A visual-first news poster (1024×1024), drawn entirely in code — no photos,
no downloaded images, no network. One huge hero dominates the top half:
**COP31 — NO DEAL**, a globe with a rising thermometer, "200 nations, 0
mentions" of fossil fuels in the draft. Below it, two story cards, each with
one big vector icon, a short title and one big number: **RAHUL 100** (first
Test century in New Zealand) and **TAKAICHI SKIPS TAIWAN TALKS**. No
paragraphs, no small text — everything stays readable when the image is
shrunk to a ~300px thumbnail.
